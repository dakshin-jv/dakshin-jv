## 🔥 Hardest problems in industry

The blocker is rarely a better model. It's whether the company can **trust, control, afford, and fit** the agent. As an applied scientist, I treat each as a measurable failure on live traffic — then change the harness, prompts, context, and graphs until the loop holds.

### 🔐 Trust & memory
Agents mix clients and act on stale or poisoned facts.
➡️ I instrument isolation and freshness, then put conflict, decay, and forget **in the harness** — not in the prompt.

### 🎯 Quality & control
Nobody can see what the agent did; a worse change still ships; "please don't" is the only brake.
➡️ I trace the loop (prompt → tool → outcome) 🔄, gate releases on evals ✅, and guardrail the tool, not just the prompt 🛡️.

### 💸 Cost
Unbounded agent loops look cheap in the pilot and explode in production 📈.
➡️ I treat spend as a first-class metric: token, time, and step ceilings per run, inside the harness.

### 🧷 Fit
A dump of files. Data that can't leave the network. A demo nobody can run on Monday.
➡️ I build on the systems they already have, keep inference inside the network when it must stay there, and leave behind a team that owns the loop — not a black box 🤝.
